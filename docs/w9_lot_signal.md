> **`none`인 동료 웨이퍼는 진짜 「재현 안 함」**이다. `none`을 빼면
> *"패턴 둘이 있을 때 같은 패턴인가"*라는 **다른 질문**이 된다.

### ① lot 내 재현성 — 클래스 동시발생

lot `l`의 라벨 웨이퍼 수 `n_l`, 그중 클래스 `c`인 수 `n_{l,c}`.

```
R_c = Σ_l n_{l,c}(n_{l,c} − 1) / Σ_l n_{l,c}(n_l − 1)
```
= *"같은 lot에서 아무 동료를 하나 뽑았을 때 그것도 `c`일 확률"*.

- **귀무**: 전체 172,950장의 **클래스 라벨만 섞는다**(lot 소속 고정). `B=999`.
  **lot 크기와 클래스 주변분포가 정확히 보존**되므로 §3-2의 부수 변수(lot 크기)가 통제된다
- **구간**: `R_c`의 **lot 블록 부트스트랩** `B=2,000`. `Edge-Ring`은 lot당 9.0장이라
  **`deff`가 크다**(D-050에서 방위 기각률이 16.20이었다) — **Wilson/이항을 쓰지 않는다**
- 보고: `R_c` · 귀무 평균 `R_c⁰` · **응집 배수 `R_c / R_c⁰`** · 순열 `p` · lot 블록 95%

### ② `waferIndex`(슬롯) 상관

- **귀무**: **lot 안에서** 라벨 웨이퍼의 슬롯 번호를 섞는다. `B=999`.
  lot의 클래스 구성과 **점유 슬롯 집합이 둘 다 보존**된다
- 기대도수는 해석적으로 구한다: `E_{c,s} = Σ_l n_{l,c}·1[s ∈ slots(l)] / n_l`,
  통계량 `T_c = Σ_s (O_{c,s} − E_{c,s})² / E_{c,s}`. 방향은 **평균 슬롯의 기대 대비 편차**로 따로 낸다
- 🔴 **검출력이 ①의 결과에 반비례한다 — 미리 적는다.** lot이 단일 클래스로 채워져 있으면
  lot 안 순열이 움직일 것이 없다. → **「섞인 lot 안의 웨이퍼 수」(유효 표본)를 클래스마다 같이 낸다.**
  이 수가 작으면 `T_c`가 비유의여도 **「슬롯 무관」이 아니라 「못 잰다」**다

### ③ 특징값의 lot 내 일관성

클래스 `c`의 웨이퍼만 쓰고, 그 클래스 웨이퍼를 **2장 이상 가진 lot**에서
특징 `f`의 **급내 상관** `ICC_f,c = 1 − SS_within / SS_total`.

- **귀무**: 클래스 `c` 안에서 **웨이퍼를 lot에 재배치**(lot별 장수 보존). `B=999`
- 🔴 **부수 변수는 웨이퍼 크기다** (§3-2). 같은 lot은 같은 제품이라 **맵 크기가 같고**,
  특징 6종은 크기와 상관이 있다(D-015: `cov` −0.457 · `F1a` +0.264 · `F1b` −0.259).
  → **`size`(유효 die 수) 자체의 ICC를 먼저 내고**, 각 특징은 **클래스 내 `log size` 선형 잔차**
  위에서 **다시 낸다**. **원값과 잔차값을 둘 다 보고한다** (§3-6 — 보정 전후를 모두 본다)

### 4-A. ⛔ **③의 귀무를 잘못 짰다. 먼저 그것부터 적는다**

1차 실행에서 ③의 귀무를 **`perm_within`(lot 안에서 섞기)**로 짰다.
**lot 안에서 섞으면 각 lot의 값 집합이 그대로라 ICC가 안 변한다** — 귀무가 관측과 같아지고
`p`가 전부 1 근처(0.58 · 0.99 · 1.00)로 나왔다. 부동소수 덧셈 순서 차이만 남아 `p`가
**무작위로 흩어져** 「비유의」처럼 보였다. 귀무는 **lot을 가로질러 재배치**해야 한다.

> 🔴 **자체 검사가 `icc()`의 양 끝(완전 일치 → 1 · 무작위 → 0)만 봤고 「귀무 구성」은 안 봤다.**
> 통계량은 맞았고 **귀무가 틀렸다.** D-051이 *"새 검사에 새 성질만 넣고 옛 성질을 뺐다"*였다면
> 이번은 ***"값 계산은 검사하고 귀무 구성은 검사하지 않았다"***다 — **같은 계열의 네 번째**다.
> **추가한 검사**: 응집 자료를 넣어 **귀무평균이 0으로 떨어지는지**(`|귀무평균| < 0.1`)와
> **`p`가 최소값인지**를 본다. 그리고 **층=lot으로 주면 검출력이 0이 되는지**까지 본다.

**둘째로 `ICC`의 무보정판은 귀무값이 0이 아니다.** 무작위여도 `E[1 − SS_w/SS_t] = (G−1)/(N−1)`이고
**`N/G`가 클래스마다 다르다**(`Edge-Ring` 9.0장/lot vs `Scratch` 1.1장/lot).
그대로 쓰면 **응집이 아니라 lot당 장수를 비교하게 된다.** 자유도로 나눴다 —
**§3-13(귀무값을 계산한다)의 세 번째 사례**이고, 이번엔 **자체 검사가 잡았다**(무작위 입력에서 ICC 0.198).

**셋째로 ②의 검출력 기준선을 관측 평균으로 잡았다.** `λ=0`의 모의가 0이 아닌 이동을 내
**이동량이 통째로 −0.25칸 밀렸다.** 기준은 **순열 기대**다 (§3-11).
처음 표에서 *"0.31칸 이동을 95.7%로 잡는다"*로 읽었는데 **옳은 값은 0.56칸**이다.
