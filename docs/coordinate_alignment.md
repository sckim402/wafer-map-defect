# 좌표계 정렬 진단

**작성 시점: W5 (9/9~9/13)**

## 왜 하는가

WM-811K에는 notch/flat 방향 정보가 없다. 웨이퍼맵의 0°가 물리적으로 무엇인지
알 수 없고, 웨이퍼들이 공통 좌표계로 정렬되어 저장됐다는 보장도 없다.

따라서 **"Edge-Loc이 특정 각도에 몰린다"는 서술은 두 가지로 해석된다:**

1. 원인이 위치적으로 고정되어 있다 (물리적 결론)
2. 애초에 좌표계가 정렬되어 있지 않다 (데이터 아티팩트)

이 둘을 구분하지 않으면 결론이 아니라 착시가 된다.

## 선행 조건

**Edge-Loc이 2장 이상 포함된 lot이 몇 개인가?** 부족하면 결론은
**"판정 불가 (표본 부족)"** — 그것도 명시할 결과다.

    확인 결과: ____ 개 lot

## 검사 (2단)

| 단계 | 검사 내용 | "몰림"이 증명하는 것 |
|---|---|---|
| 1. lot 내 | 같은 lot의 Edge-Loc 최대 밀도 방위각이 서로 몰리는가 | **그 lot 안에서의** 방향 일관성 + 위치 고정 원인 |
| 2. lot 간 | lot별 대표 방위각이 lot들 사이에서도 몰리는가 | 데이터셋 **전역** 정렬 + 계통적 원인 |

## 해석 규칙

- **lot 내 집중 + lot 간 무작위** → lot 단위 정렬. **"장비별 고정 접촉"까지가
  말할 수 있는 전부다**
- **둘 다 집중** → 전역 정렬 + 계통 원인. **notch 고정각 해석(핸들링 기구부)은
  이 경우에만 가능하다**
- **lot 내부터 무작위** → "확률적 접촉"과 "좌표계 미정렬"을 구분할 수 없다.
  **이 한계를 명시하는 것이 정직한 결론이다**

> **lot 내 집중만으로 "데이터셋이 정렬됐다"고 말하지 않는다 — 범위를 넘는 추론이다.**

## 결론이 특징 설계에 미치는 영향

**없다.** F3는 이미 회전 불변 지표(가중 circular variance)로 설계했으므로
정렬 여부와 무관하게 작동한다. 이 진단은 **notch 해석을 할 수 있는지 없는지**만
결정한다.
