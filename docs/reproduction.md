## 2. 층(layer)과 밴드 — 가장자리 3종의 토대

**반경 비율이 아니라 침식(erosion) 기반이다.** `R_CUT` 방식은 폐기됐다 (D-007).

```python
# 유효 영역(값 != 0)에서 8-이웃 침식을 반복해 최외곽부터 한 층씩 벗긴다
층 l_i = (침식 i-1회 결과) ∖ (침식 i회 결과)
밴드   = 최외곽 EDGE_LAYERS 층의 합집합

scipy.ndimage.binary_erosion(valid, structure=np.ones((3,3)), border_value=0)
```

⚠ **`border_value=0`이다** — 배열 밖은 「영역 밖」으로 본다. 저장된 맵 경계에 붙은 die는
**최외곽 층에 들어간다.** 이걸 `border_value=1`로 두면 **`n_band`가 전수에서 바뀐다**
(5차 외부 검토 실측: 2,119/2,119장, 최대 차 86 die).

| 상수 | 값 | 쓰임 |
|---|---|---|
| `EDGE_LAYERS` | **1** | 밴드 두께 (D-007) |
| `MAX_LAYERS` | 8 | 층별 프로파일 관측 범위 |
| `INNER_FROM, INNER_TO` | **3, 6** | `edge_contrast`의 내부 기준층 (2층은 링 번짐이 섞인다) |
| `N_WEIGHT_BINS` | 36 | `circ_var` 가중치 정규화 |
| `MIN_FAIL` | 12 | **밴드 안 불량 die 수**가 이 미만이면 `circ_var` = NaN (전체 불량 수가 아니다) |
| `SUBSAMPLE_N` | 20 | 개수 통제 **실험 전용** (D-008). ⚠ **최종 특징 계산에는 적용하지 않는다** |
| `MAX_FAIL` | 4000 | 초과하면 `cc_compact` = NaN |
| `ALPHA` | 1.0 | Laplace 평활 |
| `DISK` | √π/2 ≈ 0.8862 | 원판 기준선 |

## 3. 특징 6종 — 전부 **웨이퍼 내부 기준 대조비**다

| 이름 | 정의 | 겨냥 |
|---|---|---|
| `coverage` | 밴드 안 불량 die 수 / 밴드 die 수 | 둘레를 얼마나 덮었나 |
| `edge_contrast` | `(f₁+α)/(n₁+2α)` ÷ `(f₃₋₆+α)/(n₃₋₆+2α)`. **`f₃₋₆ = Σ_{l=3..6} f_l`, `n₃₋₆ = Σ n_l`** — 층별 비율의 평균이 **아니다**. ⚠ **`n₁=0`이거나 `n₃₋₆=0`이면 NaN이다** — 평활이 있어 0으로 나눌 일이 없는데도 **코드에 별도 가드가 있다**(§5) | 가장자리 대 내부 |
| `circular variance` | `1 − |Σ wₖ e^{iθₖ}| / Σ wₖ`, **밴드의 불량 die만** 합산. 가중치 `wₖ = 1/(θₖ가 속한 bin의 밴드 die 수)` — 분모는 **정상 die도 포함한 밴드 전체** | 어떻게 흩어졌나 |
| `F1a` (`radial_contrast`) | `rate(r<R1) / rate(r≥R2)` | `Center` |
| `F1b` (`mid_peak`) | `rate(R1≤r<R2) / max(안, 밖)` | `Donut` |
| `cc_compact` | `(n/L) / (DISK·√n)`, `n`=최대 8-이웃 연결성분 크기, `L`=주축 투영 범위+1 | 선형성 |

- `rate(mask)` = `(불량 수 + α) / (die 수 + 2α)`
- **반경 `r`은 타원 정규화다** — 유효 영역 bounding box 중심에서 **축별 반장으로 나눈다**
  (`r = hypot((y−cy)/hy, (x−cx)/hx)`). 원형 가정으로 짜면 F1a·F1b가 달라진다
  - **중심과 반장은 die 중심 좌표 기준이다**: `cy = (row_min+row_max)/2`,
    **`hy = (row_max−row_min)/2`** (칸 폭을 더한 `+1`이 **아니다**). `hx`도 같다.
    0이면 `1e-9`로 바닥을 둔다. ⚠ **`+1`을 붙이면 F1a·F1b가 전수에서 바뀐다**
    (5차 실측: 2,119/2,119장)
  - ⚠ **`circ_var`의 방위각도 같은 타원 좌표에서 잰다** —
    `θ = arctan2((y−cy)/hy, (x−cx)/hx)`. **원래 격자에서 재면 값이 달라진다.**
    이 줄이 없어서 5차 검토자가 격자 좌표로 읽었다
- ⚠ **`circ_var`의 bin 규칙은 아래 한 줄이 전부다** (6차 외부 검토 #1 — *"digitize 쪽"*
  이라고만 써서 **θ=π를 어느 bin에 넣는지가 안 정해졌다.** 두 해석 사이
  **2,153장 중 1,225장(56.9%)의 값이 다르고** 최대 |Δ|는 0.032다):

  ```python
  edges = np.linspace(-np.pi, np.pi, n_bins + 1)          # 37개 경계
  idx = np.clip(np.digitize(theta, edges) - 1, 0, n_bins - 1)   # right=False(기본)
  ```
  **`clip`이므로 θ=π는 마지막 bin(35)에 들어간다.** `mod 36`으로 첫 bin에 돌리지 않는다.

- **`R1 = 1/3, R2 = 2/3`은 임의값**이다 (유효 반경 3등분). 성능으로 고르지 않았다는 것만 보장된다
- `cc_compact`의 주축은 `np.linalg.eigh(cov)`의 **최대 고유값 쪽 고유벡터**다.
  좌표는 최대 성분 die의 **(행, 열) 중심**, 공분산 분모는 **`np.cov` 기본값 `n−1`**.
  `MAX_FAIL = 4000`은 **맵 전체 불량 수**에 건다(최대 성분 크기가 아니다).
  **최대 크기 성분이 여럿이면 `scipy.ndimage.label`의 번호가 작은 쪽**을 쓴다
  — ⚠ 이건 **규칙이 아니라 구현 부작용**이고, 결함으로 §5에 적어 뒀다
  - ⚠ **퇴화 처리 두 단** (6차 외부 검토 doc_gap 2): ⓐ **맵 전체 불량 수** `tot`가
    `3` 미만이거나 `MAX_FAIL` 초과면 **`cc_n`부터 NaN**이다 ⓑ `tot`는 통과했는데
    **최대 성분 크기 `n`이 3 미만**이면 **`cc_n`은 실제 크기를 남기고 `cc_compact`만 NaN**이다.
    ⚠ **이유를 정정한다 (7차 외부 검토).** *"`n−1` 분모와 `eigh`가 정의되지 않는다"*고
    적었으나 **틀렸다** — `n=2`면 `np.cov`(ddof=1)도 `eigh`도 정의된다.
    **수학적으로 미정의인 것은 `n=1`뿐**이고, **`n<3` 배제는 규약이지 필연이 아니다**
    (2 die는 주축이 항상 그 둘을 잇는 선이라 `cc_compact`가 기하가 아니라 상수를 잰다).
    **`n=1`을 `1/DISK`로 메우지 않는다**

**⚠ 결측은 대치하지 않고 NaN 그대로 RandomForest에 넣는다.** NaN 비율이 클래스마다 다르므로
0으로 채우면 다른 수치가 나온다.

## 7. 초록에 실린 수치의 정의 — **2026-09-12 신설 (D-033)**

**1~6차 외부 검토는 특징 6종의 값과 방위 검정만 봤다.** 초록의 나머지 수치는
**한 번도 외부에서 재계산된 적이 없다.** 그 정의를 여기 모은다.

### 7-1. 3단계 특징 집합

| 단계 | 특징 |
|---|---|
| 가장자리 3종 | `coverage` · `edge_contrast` · `circ_var` |
| + 반경 2종 | 위 3종 + `radial_contrast` · `mid_peak` |
| + 형상 1종 | 위 5종 + `cc_compact` |

**세 단계 모두 같은 분류기·같은 분할이다** (§4). 단계마다 열만 늘린다.

### 7-2. 혼동 쌍의 대표값은 **seed 3개 평균**이다

쌍 28개 각각에 대해 seed별 상호 오분류율을 내고 **평균한 뒤** 최댓값을 고른다.
⚠ **seed 하나로 고르면 1단계 승자가 바뀐다** — `seed 0`에서는
`Loc↔Scratch`(0.191)가 `Center↔Loc`(0.188)보다 앞선다. **평균이 규약이다.**

### 7-3. 누수 규모 — 「웨이퍼 단위로 나눴다면」

**모델 없이** 잰다. 정본 인덱스(§7-6)에서

```python
rng = np.random.default_rng(44)                 # config.SEED
te = np.zeros(N, bool); te[rng.choice(N, int(N * 0.2), replace=False)] = True
비율 = (test 웨이퍼의 lot이 train lot 집합에 있는 비율)
```

**`int(N*0.2)`이고 층화하지 않는다.** 클래스별 값도 같은 한 번의 추출에서 낸다.
⚠ **정본 인덱스 순서가 다르면 `rng.choice` 결과가 달라진다.**

### 7-4. 층별 불량률 비 (`Edge-Loc ÷ Loc`)

층 `l`의 불량률 = **클래스 전수에서** `Σ(층 l의 불량 die) / Σ(층 l의 die)`.
**웨이퍼별 비율의 평균이 아니다** — 그쪽은 작은 맵에 큰 가중치를 줘서
6층 비가 1.02가 아니라 0.89가 된다. **부분표본도 쓰지 않는다.** `l = 1..6`.

> ⚠ **2026-08-13에 적어 둔 표의 `Loc` 열은 이 정의로 재현되지 않는다** (D-033).
> `Edge-Loc` 열은 소수점 셋째 자리까지 맞는데 `Loc`만 계통적으로 낮다
> (전수·부분표본·웨이퍼평균 **어느 정의로도** 안 나온다). **재현되는 쪽을 채택했고
> 초록 수치를 v8에서 고쳤다.**

### 7-5. 단일 특징 `|AUC − 0.5|`

`Edge-Loc`(양성) vs `Loc`(음성), **특징 6종 각각**, 맵 전수.
Mann-Whitney U / (n₊·n₋). **NaN은 각 쪽에서 먼저 버린다.**
**동점에는 평균 순위**(`scipy.stats.rankdata`) — 서수 순위로 짜면 완전 동점 입력이
0.5가 아니라 0이 된다(§5).

### 7-6. 정본 인덱스 — 이것이 안 맞으면 §7-3이 안 맞는다

`config.PATTERN_CLASSES` 순서(`Center · Donut · Edge-Loc · Edge-Ring · Loc ·
Near-full · Random · Scratch`)로 이어 붙이고, **각 클래스 안은 원본 `.npz` 순서**다.
제공 데이터의 `idx` 열이 이 순서다.

### 7-7. 방위 국소성 검정 (D-028 → D-032)

**통계량**: 최외곽 1층 불량 die의 **최대 연속 90° 호 점유율**.

| 항목 | 값 |
|---|---|
| 최외곽 1층 | 유효 die 중 **8-이웃에 영역 밖이 하나라도 있는** die (§2의 1층과 같다) |
| 중심 | **유효 die 좌표의 산술평균**. ⚠ `circ_var`의 bbox 중심·타원 정규화와 **다르다** |
| 각도 | `degrees(arctan2(y − cy, x − cx)) % 360`. **타원 정규화 없음** |
| 호 | 시작점 `0, 10, …, 350`° · 폭 **90°** · **닫힘 `[s, s+90]`**. ⚠ **10° 격자 위의 최대값**이지 모든 시작점의 최대값이 아니다(8차 C1) |
| 중심 die | **무게중심에 정확히 놓인 die는 층에서 뺀다** — `arctan2(0,0)=0`이 **가짜 0°**를 주고 반사에서 값이 바뀐다(8차 C2). 현행 자료에는 **0개** |
| 귀무 | 같은 층의 유효 die 위에 **같은 개수**를 비복원 재배치. `B = 999` |
| p | `(1 + #{귀무 ≥ 관측}) / (B + 1)`, 기각선 `p ≤ 0.05` |
| 제외 | 최외곽 층 die < **20**, 층 안 불량 < **3**, **층이 전부 불량**(모든 재배치가 같아 검정이 퇴화) |
| 표본 | 클래스당 **400장** 비복원. 클래스 `ci`(정본 순서 0~7)마다 **`default_rng([20260912, ci])`** — 클래스별로 독립이다 |
| 귀무 RNG | 맵마다 **`default_rng([20260912, ci, 클래스 내 원본 인덱스, 0])`** — **표본 순서와 무관**하다 |
| 제외 순서 | **먼저 400장을 뽑고 그 다음 제외**한다. 분모는 **적격 표본 수**(뽑은 400이 아니다) |
| 400장 미만 클래스 | `Near-full`(149장)은 **전량**. `permutation` 뒤 앞에서부터 자르므로 순서만 섞인다 |

⚠ **호를 반열림으로 두면 좌우 반사에서 값이 바뀐다**(§5). 닫아야 한다.

⚠ **표본 RNG와 귀무 RNG를 분리해야 한다** (7차 외부 검토 A1·A2, **`high` 2건**).
전에는 **RNG 하나가 둘을 번갈아 소비**해서, `Edge-Loc`의 표본이 **앞 클래스들이 소비한
난수 개수**에 달려 있었다 — `B`나 `N_PER`을 바꾸면 표본이 통째로 바뀐다.
검토자가 클래스마다 RNG를 새로 만들자 **`Edge-Loc` 400장 중 370장이 교체**됐고
기각률이 **−4.75%p** 움직였다. 제외를 추출 앞으로 옮기면 `Edge-Ring` 분모가
386→400으로 바뀌며 **−3.18%p**였다.

⚠ **이 통계량의 정확한 이름은 「10° 간격 36개 시작점에서 잡은 닫힌 90° 호의 최대 불량
점유율」이다** (8차 외부 검토 C1). **임의 각도 회전 불변량이 아니다** — 불량 각도가
`[5°, 94°, 185°]`이면 값이 `1/3`인데 원점을 5° 옮기면 `2/3`이다.
**파급은 쟀다**: 연속 시작점으로 바꾸면 전수 8,560장 중 **3,916장의 통계량과 439장의
판정**이 바뀌지만 기각률은 **71.8/20.3% → 71.1/20.7%**, 차이 구간 **48.2~52.6%p**로
**집계 결론은 유지된다.** 연속 시작점판은 **별도 변경안**이고 현행은 격자판이다.

⚠ **귀무 기각률이 반드시 5%는 아니다** (8차, 전수 열거로 확인). 원주 20점·`k=5`의
**15,504개 배치 전수**에서 기각률은 **0.2322%**이고 `k=3`이면 **0%**다.
**이산성 때문에 명목보다 낮아진다 — 5%에 못 미치는 것을 결함으로 읽지 않는다.**
(D-032가 *"Center 8.2% = 자연 귀무 기준선"*을 철회한 것과 같은 뿌리다.)

⚠ **기각률에는 몬테카를로 잡음이 있다** (7차 A3). `B=999`에서 **귀무 seed만** 바꿔도
`Random`이 10개 seed에서 **21.75~23.25%**로 움직인다. `p`가 0.05 근처인 맵의 판정이
흔들리기 때문이다. **그래서 이 표는 소수점 첫째 자리를 인용하지 않는다 — 방향만 쓴다.**

⛔ **「400장이면 이항 오차 ±2%p」는 내가 잘못 쓴 값이다** (8차 검토 §5).
**Wilson 95% 반폭은 `Edge-Loc` 4.37%p · `Loc` 3.97%p**다. 그리고 **몬테카를로 폭 ·
웨이퍼 표본 오차 · lot 군집 오차는 서로 다른 양이라 섞지 않는다** — 현행 표본 차이의
lot 구간은 **46.7~59.3%p**다.

⛔ **이 검정이 식별하지 않는 것** — 덩어리 **개수**(반대편 두 덩어리도 기각된다)와
**내부 구배**(최외곽 층만 읽는다). 그리고 **검출력이 층 안 불량 수에 강하게 붙으므로**
클래스 간 기각률의 **배수를 국소성의 크기로 읽으면 안 된다** (D-032).
