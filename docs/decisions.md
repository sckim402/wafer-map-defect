# 설계 판단 기록

코드는 3개월 뒤 잊히지만 "왜 그렇게 판단했는가"는 남는다. 결정을 내릴 때마다
여기에 한 항목씩 추가한다. **길게 쓸 필요 없다. 안 쓰는 것이 문제다.**

기록 형식:

    ## D-00X. 무엇을 결정했나
    - 날짜:
    - 선택지: A / B / C
    - 선택: B
    - 이유:
    - 버린 이유:
    - 나중에 뒤집을 조건:

마지막 항목이 중요하다. **뒤집을 조건을 못 쓰면 근거 없이 고른 것이다.**

## D-001. 원본 pkl을 매번 읽지 않고 클래스별 npz로 변환한다

- 날짜: 2026-08-__
- 선택지: (A) 매번 pkl 로드 / (B) 클래스별 npz로 1회 변환
- 선택: **B**
- 이유: pkl 로드에 매번 수십 초 + 수 GB 메모리. 주 5~10시간짜리 프로젝트에서
  반복 비용이 누적된다. 클래스 단위로 나누면 필요한 것만 읽을 수 있다.
- 버린 이유: (A)는 단순하지만 세션마다 같은 비용을 다시 낸다.
- 뒤집을 조건: 웨이퍼 단위 무작위 접근이 필요해지면 (예: lot 단위 분할을
  전체 데이터에서 한 번에 해야 할 때) 통합 인덱스를 별도로 둔다.

---

## D-002. 분류 대상을 패턴 8종으로 한다 (none 제외)

- 날짜: 2026-08-__
- 선택지: (A) 9종 전체 / (B) 패턴 8종만 / (C) 2단계 (검출 -> 분류)
- 선택: **B**
- 이유: 이 프로젝트의 목적은 "불량 검출"이 아니라 "검출된 패턴의 원인 규명"이다.
  none은 라벨 보유분의 약 85%라, 포함하면 오류의 대부분이 (패턴 <-> none)이 되어
  **정작 보고 싶은 Edge 계열 혼동이 묻힌다.**
- 버린 이유: (A)는 confusion matrix가 none에 지배된다. (C)는 옳지만 시간이 없다.
- 한계로 명시할 문장: *"실제 fab에서는 불량 검출이 선행되므로 본 연구는 검출
  이후 단계를 다룬다."*
- 뒤집을 조건: Phase 5에서 시간이 생기면 (C)로 확장한다.

## D-003. train/test 분할을 lotName 기준으로 한다

- 날짜: 2026-08-__
- 선택지: (A) 웨이퍼 단위 random split / (B) lotName 기준 GroupShuffleSplit
- 선택: **B** (+ 원저자 `trainTestLabel` 분할 병행 검증)
- 이유: 같은 lot의 웨이퍼는 공정 조건이 같아 강하게 상관된다. 웨이퍼 단위
  random split은 같은 lot을 train과 test에 갈라 넣는 **data leakage**를 만들고,
  "특징 추가로 오분류 감소"라는 핵심 수치를 부풀린다.
- 버린 이유: (A)는 흔하지만 이 데이터에서는 틀린 선택이다.
- 뒤집을 조건: 없음. 두 분할에서 결론이 갈리면 그 사실 자체를 보고한다.

## D-004. (작성 예정) 리사이즈 여부

- 선택지: (A) 64x64 리사이즈 / (B) native grid에서 정규화 좌표로 직접 계산
- 검토 사항: 64x64는 CNN용 습관이다. 특징 기반 경로에서는 보간 왜곡이 없는 쪽이
  낫다. **median filter는 작은 맵에서 1-die 폭 Scratch를 통째로 지울 수 있다 —
  클래스별 전후 확인 없이 적용 금지.**

---

## D-005. (작성 예정) 각도 bin 수

- 검토 사항: max/mean ratio와 엔트로피는 bin 수에 의존한다. 작은 맵은 bin당
  die가 적어 노이즈가 크다. 맵 크기와 연동한 규칙이 필요하다.
  **가중 circular variance는 bin에 의존하지 않으므로 F3의 대표 지표로 삼는다.**

---

## 안 하기로 한 것들

시간 제약으로 뺀 항목도 판단이다. **왜 뺐는지를 안 쓰면 그냥 못 한 것이 된다.**

| 항목 | 뺀 이유 | 복구 시점 |
|---|---|---|
| CNN | 초록에 불필요. 12주 안에 안 들어감 | Phase 5 |
| 13-zone 밀도 특징 | F1·F3와 정보 중복 가능성. 일정 압축 | 여유 시 |
| F3 보조 지표 (max/mean, 엔트로피) | 대표 지표 하나로 검증 가능 | 여유 시 |
| none 포함 2단계 파이프라인 | D-002 참조 | Phase 5 |
