### 1-A. 무엇이 자명하고 무엇이 아닌가 — ⚠ 최초 설계의 결함을 먼저 정정한다

**폐기한 기준 (2026-09-08에 제안됐던 것)**:
*"6경로 전부에서 마지막 병목이 `Edge-Loc↔Loc`이면 ⓑ가 선다"*
→ ❌ **검사가 아니다.** 6경로의 3단계는 **전부 같은 6종 모델**이므로
최종 병목이 같은 것은 **결과가 아니라 정의**다. 귀무 상태에서 100% 일치한다.
**§3-13이 경고한 「귀무값을 계산하지 않은 검사」의 재발이었다.**

| | 자명한가 |
|---|---|
| 3단계(6종) 최종 병목이 6경로에서 같다 | ✅ **자명.** 판정 대상 아님 |
| 1·2단계의 최대 병목 | ❌ 자명하지 않다 |
| **각 계열이 「무엇을 푸는가」가 투입 위치와 무관한가** | ❌ **자명하지 않다. 이것이 초록의 실제 주장이다** |

초록의 주장은 *"반경을 더하자 `Center↔Loc`이 풀렸고, 형상을 더하자
`Loc↔Scratch`가 풀렸다"* — **「계열 ↔ 그것이 푸는 병목」의 대응**이다.
따라서 검사할 것은 **그 대응이 순서와 무관하게 유지되는가**다.

### 1-B. 설계

계열 3개로 묶는다 (초록의 서술 단위와 동일):

| 계열 | 특징 |
|---|---|
| **E** 가장자리 | `coverage` · `edge_contrast` · `circular variance` |
| **R** 반경 | `F1a`(radial_contrast) · `F1b`(mid_peak) |
| **S** 형상 | `cc_compact` |

- **경로 6개** — `E→R→S` · `E→S→R` · `R→E→S` · `R→S→E` · `S→E→R` · `S→R→E`
- 각 경로마다 1·2·3단계의 **최대 혼동 쌍**과 macro-F1을 낸다
- **계열 X가 푸는 쌍** = 선행 집합 `P`에서 `P∪{X}`로 갈 때 **상호 오분류율이
  가장 크게 감소한 쌍**. 각 계열은 선행 집합이 **3가지**다 (∅ / 다른 1계열 / 다른 2계열)
- **leave-one-out**: 6종 − 각 1개 (6조합). 대체 불가능한 기여를 잰다
- 분할·모델은 기존과 동일 — `StratifiedGroupKFold(5)` seed 0/1/2, RF 300 · `class_weight="balanced"`
- **외부 분할(`split_orig`) 병기** (D-016)

### 1-C. 판정 기준 — **결과를 보기 전에 확정한다**

| # | 확인할 것 | 판정 |
|---|---|---|
| **(가)** ★ | 각 계열 X에 대해, **서로 다른 선행 집합 3가지에서 「X가 가장 크게 푸는 쌍」이 동일한가** | **3계열 전부 동일 → ⓑ 성립. 초록 무수정**<br>**하나라도 갈리면 → ⓐ. 초록에 「우리가 밟은 진단 경로에서」 삽입** |
| (나) | 6경로 × 1·2단계의 최대 병목 | **전량 표로 보고.** 승자만 쓰지 않는다(§3-9) |
| (다) | leave-one-out macro 하락 | **< 0.01이면 「다른 특징으로 대체 가능」으로 기록.** **제외한다는 뜻이 아니다** (D-014·D-015 선례) |

**(가)의 동률 처리**: 최대 감소 쌍과 2위의 차이가 **0.005 미만**이면 「구분 불가」로
기록하고 **갈린 것으로 간주한다** (보수적으로 ⓐ 쪽).

**보고 원칙**: 곡선 전체를 보고한다. **주 분할과 외부 분할을 병기한다**(D-016).
`|AUC−0.5|`가 아니라 **쌍별 상호 오분류율**로 읽는다(초록과 같은 지표).

### 1-D. 이번 실행에서 **제외하는 것**과 이유

- ⬜ **개수 통제(D-008) 반복** — **이번에 하지 않는다.**
